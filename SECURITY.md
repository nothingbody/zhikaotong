# Security

Please report vulnerabilities through this repository's private vulnerability
reporting interface when available. Do not include student identities, school
question banks, database dumps, passwords, tokens, signing keys or production
connection details in public issues or pull requests.

Use independent credentials for each deployment, keep the database and backup
volume private, and place public traffic behind the documented HTTPS gateways.
The development account passwords in automated tests are synthetic fixtures and
must not be reused in a deployed school environment.
